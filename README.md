# KOMPETEN — HRIS & Koperasi Karyawan PT Primaplast Indonesia

Sistem HRIS dan Koperasi Karyawan internal PT Primaplast Indonesia: rekrutmen, kepegawaian, kehadiran, payroll, dan koperasi dalam satu aplikasi.

## Tech Stack
- React 19 + TypeScript + Vite
- Tailwind CSS v4 + shadcn/ui
- Lucide React
- Sonner (Toast)

## Cara Menjalankan
1. Instal dependensi:
   ```bash
   pnpm install
   ```
2. Jalankan development server:
   ```bash
   pnpm dev
   ```
3. Type-check & Build:
   ```bash
   pnpm exec tsc -b
   pnpm build
   ```
